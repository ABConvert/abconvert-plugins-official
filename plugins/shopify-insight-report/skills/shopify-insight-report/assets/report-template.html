Source and how to check

Charts use your Shopify reports, store-local days ({{TIMEZONE_CITY}}). To check a number, copy the ShopifyQL next to the chart and run it in the ShopifyQL editor in Shopify Analytics. Hourly rows come back in UTC, so the hourly chart shifts them by {{UTC_OFFSET_HOURS}} hours. Data was pulled {{PULL_TIME}}, so {{PULL_DAY}} is a partial day. The web_performance dataset lags about 2 days.

Definitions

sessions_with_cart_additions, sessions_that_reached_checkout, and sessions_that_completed_checkout are Shopify's session-level funnel counts, human sessions only. The ratio chart divides one by the previous for each day. It can go above 1 because a session can reach checkout without adding to cart in that same session, for example a returning visitor with a saved cart, a Buy it now button, or an abandoned-checkout email link. Read it as a before-and-after signal, not a conversion rate.

orders and total_sales come from the Shopify sales dataset and include each sales channel.
